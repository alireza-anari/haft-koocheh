# Decisions — phase 0.1

1. Approved: Godot 4.7.2 Stable Standard only; no .NET, Beta, Dev or substitution.
2. Approved: GDScript, 2D, modular directories, Android target.
3. Approved: Compatibility renderer on desktop and mobile.
4. Approved: 1280×720, landscape, canvas_items stretch, keep base aspect ratio.
5. Approved baseline applied: 60 physics ticks per second; no gameplay physics.
6. Approved: scenes/app/main.tscn is the entry, containing a title only.
7. Implementation: no gameplay script or extra dependency until required.
8. Implementation: local repository inside HAFT_KOOCHEH; no remote or push.
9. Implementation: ZIP preserves empty module directories; documented command
   restores them after Git clone without adding unused placeholder files.
10. Baseline: OpenJDK 17 for Android; Java 21 runtime observed, not silently
    treated as a verified JDK 17. Official docs allow higher JDK versions.
11. Gate: no phase 0.2 or gameplay until project-manager approval of phase 0.1.
12. Approved: no Release key, signing-secret request, release output or publish.

و project.godot تغییر نمی‌کنند. تست‌های قدیمی حفظ و شرط ممنوعیت کل gameplay با
allowlist دقیق همین سه اسکریپت/سه صحنه جایگزین می‌شود؛ دامنه‌های ممنوع همچنان رد می‌شوند.
