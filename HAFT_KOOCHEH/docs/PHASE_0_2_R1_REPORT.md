خروجی: 4.7.2.stable.official.ed1daf0bf.

## نتیجه QA-001 و مشکلات باقی‌مانده

**QA-001: FAIL؛ باز.** تصویر Main در سه اندازه موفق است، اما Editor با انتخاب صریح
OpenGL و Cache تازه نیز نمای ناقص داشت و خطاهای زیر را ثبت کرد:

- Required Vulkan instance extension VK_KHR_surface not found.
- Condition err != OK؛ initialize در rendering_context_driver_vulkan.cpp.

خطای Runtime/Resource/Renderer در سه اجرای Main دیده نشد؛ هشدار نبود پشتیبانی
تغییر V-Sync در driver در لاگ‌ها هست. خطاهای تاریخی import شواهد اصلاح شدند؛ خطای
Vulkan در Editor نهایی همچنان باقی است. علت ریشه‌ای نمایش ناقص Editor در این میزبان
قطعاً تشخیص داده نشده و ادعای رفع آن نداریم. بررسی متنی و Headless ساختار Main
را پوشش می‌دهد ولی جای بازبینی درخت صحنه در Editor سالم را نمی‌گیرد.

نیاز باقی‌مانده: اجرای Editor سالم با همین 4.7.2 Standard/Compatibility روی میزبان
یا driver سازگار، ثبت tree واقعی Main/UI/Title، log و شواهد مطابق QA_TEST_PLAN.
هیچ تغییر فناوری یا دامنه محصول برای رفع این محدودیت خودسرانه انجام نشده است.
